# dsh-wsl-hostsvc

DeepSeek Harness 插件：从 WSL 探测 Windows 主机上的本机服务（如 Ollama），并给出可达 baseURL。

配套 **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**。

[English → README.md](./README.md)

## 安装

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-hostsvc
```

重启 `dsh web` 并开**新**会话。工具名：`host_reach`。
